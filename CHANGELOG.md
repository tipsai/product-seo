# Changelog

## 0.1.0 (2026-11-16)

First public version.

- One skill, `product-seo`, for Claude Code, Codex, Cursor and claude.ai. Installs with `npx skills`, as a Claude Code plugin, as a Codex plugin, or from a ZIP.
- Plays: triage into two piles, what to write about, page workflow, auditing existing pages, task pages and tools, comparison pages, titles and snippets, cleanup and merge, links and listings, AI search, measure and roll back, optional publishing.
- Templates: site profile, product facts, change log, lessons, listing kit, a list of 63 places to get listed, an `llms.txt` template, an HTML cover template, a drop-in clickable table of contents, and a block for the project's `CLAUDE.md` or `AGENTS.md`.
- Seven Node.js scripts with no dependencies: `gsc-fetch`, `opportunities`, `coverage`, `measure`, `indexnow`, `shoot`, `brand` (the last two need Playwright).
- README in English and Russian, and a Russian playbook in `docs/ru/`.

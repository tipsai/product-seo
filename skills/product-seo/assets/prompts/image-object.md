# Prompt: one object without text

For the image model. It draws the object only. Headlines, captions and interface are added afterwards in HTML (`references/images.md`).

Replace the brackets with the colours from `seo/brand.md` (`scripts/brand.mjs` reads them from the site). If the generator accepts reference images, attach two or three from the site so the style matches.

```
STYLE:
- Soft glossy 3D "app icon" object: rounded squircle silhouette, smooth plastic or clay surface, gentle top-left light, soft inner highlights, subtle gradients inside each colour, no hard outlines.
- A thick clean WHITE RIM around the object, like a die-cut sticker, and a soft, short drop shadow underneath.
- Slight tilt (5-12 degrees), seen almost front-on, minimal perspective. Chunky, friendly proportions.
- Palette: [main brand colour] with [lighter highlight], [accent colour], white #ffffff, light gray #e5e7eb, dark ink #111827 only for tiny accents. No purple, no neon, no rainbow.
- Absolutely NO letters, words, numbers or fake text anywhere. Lines of text are shown only as rounded gray or brand-colour bars.
- No hands, no people, no desk, no background scene, no sparkles, no confetti, no lens flare.
- Single isolated object, centered, generous padding, TRANSPARENT background.
- Clean, premium, product-design quality, not generic clip-art.

OBJECT: [one or two sentences: the shape, what is on it as simple bars and icons, colours from the palette, tilt 6-10 degrees]
```

This is one style among several. Do not use it for every cover: see "Variety" in `references/images.md`.

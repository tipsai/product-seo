# seo/

Working notes for SEO on this site. Kept by the agent, readable by people. Start with the first three files.

| Path | What it is |
|---|---|
| `site-profile.md` | The product, who pays, the two piles of topics, the owner's standing decisions, where product changes and analytics are found, the date product changes were last checked |
| `change-log.md` | Every change to the site with its backup and check dates, and the results of the checks |
| `lessons.md` | What worked and what to do differently; read before every new page |
| `product-facts.md` | The only source for anything written about the product; every line dated |
| `experiments.md` | One hypothesis per page and its result |
| `sources/` | Facts about other products: quote, link, date. One file per product |
| `backups/` | Old versions of changed pages, named by slug and date |
| `data/` | Search Console rows and exports. Not in git |
| `shots/` | Screenshots from checks. Not in git |
| `listings/` | Texts for directory forms and the checklist of places |
| `audits/` | Page audit reports, one per date |
| `drafts/` | Pages being written, one folder per page |

Add a line here whenever a new file or folder appears.
